## 2. Mathematical Muscle Dynamics Formulations

### 2.1 Modeled Muscle-Tendon Length ($l_{MT}$)
The instantaneous straight-line or wrapped muscle-tendon length is computed from the 3D transformed Euclidean distance between the origin point $\mathbf{p}_{orig} \in \mathbb{R}^3$ and insertion point $\mathbf{p}_{ins} \in \mathbb{R}^3$:
$$l_{MT}(\theta) = \|\mathbf{p}_{ins}(\theta) - \mathbf{p}_{orig}(\theta)\|_2$$

### 2.2 Modeled Fiber Length ($l_M$) & Delta Length ($\Delta l_M$)
Assuming an inelastic tendon at low force ($l_T \approx l_{T,s}$):
$$l_M(\theta) = \frac{l_{MT}(\theta) - l_{T,s}}{\cos(\alpha)}$$
$$\Delta l_M(\theta) = l_M(\theta) - l_M(0^\circ)$$

### 2.3 Normalized Fiber Length ($\tilde{l}_M$) & KMSI Classification
$$\tilde{l}_M(\theta) = \frac{l_M(\theta)}{l_{M,0}}$$

| $\tilde{l}_M$ Range | KMSI Tag | Color Hex | Physiological State |
|---|---|---|---|
| $\tilde{l}_M < 0.85$ | `SHORTENED` | `#3498db` (Blue) | Significant active shortening / myofilament overlap crowding |
| $0.85 \le \tilde{l}_M \le 1.15$ | `NOMINAL_RESTING` | `#95a5a6` (Gray) | Operating near optimal cross-bridge overlap |
| $1.15 < \tilde{l}_M \le 1.35$ | `MODERATE_STRETCH` | `#f39c12` (Amber) | Ascending limb of passive elastic titin resistance |
| $\tilde{l}_M > 1.35$ | `HIGH_STRETCH` | `#e74c3c` (Red) | High passive elastic connective tissue tension |

### 2.4 Modeled Passive Force ($F^{pe}$)
Passive elastic resistance generated by intramuscular connective tissue and giant sarcomeric titin proteins is modeled via the Millard 2012 / Thelen 2003 exponential formulation:
$$F^{pe}(\theta) = F_{max}^{iso} \cdot \left(\frac{\max(0, \tilde{l}_M(\theta) - 1.0)}{k_{pe}}\right)^2, \quad k_{pe} = 0.6$$

## 3. Four Mandatory Epistemic Badges (P15-E)

Every muscle dynamic record and UI inspector view renders four mandatory epistemic distinction tags to prevent misinterpretation:

1. `MODELED_LENGTH_CHANGE`: Geometric path computation derived from OpenSim 4.6 kinematic forward models.
2. `MODELED_PASSIVE_FORCE`: Simulated elastic tissue resistance; does not measure active metabolic contraction.
3. `MUSCLE_ACTIVATION_NOT_MEASURED`: Invariant reminder that surface or needle electromyography (EMG) is NOT recorded.
4. `EDUCATIONAL_ILLUSTRATION`: Biomechanical teaching model; not a clinical diagnostic measurement.

## 4. Epistemic Safety Under Comparative Restricted Scenarios

When the workstation is switched to **Model B: Forward Shoulder Restricted (4:1 Scapulohumeral Rhythm)**:
- Scapular upward rotation is restricted to $12^\circ$ at $90^\circ$ elevation, inducing subacromial compromise.
- **Fail-Closed Safety Guarantee:** Because OpenSim does not simulate dynamic force recalculation for pathological scapular dyskinesis, the engine **strictly flags all muscle metrics** as:
  $$\text{validation\_status} = \text{"NOT\_VERIFIED\_FOR\_MODIFIED\_POSTURE"}$$
- UI displays a visible amber caution alert (`#dyn-alert-restricted`):
  > **CAUTION:** Unadjusted baseline estimate. OpenSim has not re-simulated altered kinematics for restricted posture.
- This prevents misleading researchers into assuming baseline muscle forces reflect pathological scapular winging or restriction.
